# Workspace assistant — independent release review

Date: 2026-10-14

Release decision: **PASS**. No unresolved blocking findings in the reviewed assistant implementation.

## Scope and evidence

Reviewed `lib/assistant-engine.ts`, `lib/assistant-worker.ts`, the integration in `components/ResearchAssistant.tsx`, the retrieval checks, and the exported worker wiring. Independently inspected the desktop and mobile screenshots. This is a focused release review, not a claim of compatibility with every browser or device.

The assistant uses genuine local model generation through the installed `@mlc-ai/web-llm` 0.2.85 package. Research mode is explicitly identified as source-based retrieval, separately from local AI. The model is grounded with the saved workspace research; it is not represented as fine-tuned on SEOasis or connected to private accounts.

## Findings corrected during review

1. Generation originally relied on `interruptGenerate()` alone. A stopped worker can leave its pending RPC unresolved. Generation now races against explicit cancellation/failure, rejects promptly, and ignores stale tokens with generation IDs.
2. A generation timeout now terminates the worker and resets the ready engine, allowing a subsequent enable action to start a new model instance.
3. Worker failures reject the active load or generation, reset the engine, and return the interface to source-based research. Stale worker error events are ignored after the load version changes.
4. Context packing was reduced and now keeps every supplied evidence number within the bounded model context.
5. Qwen3.5 thinking is disabled through `extra_body`; the known empty thinking prefix is removed before JSON parsing. Arbitrary reasoning bodies are not silently stripped.
6. The proposed next step is extracted from a cited research record's documented action. It is not generated by the model.

## Practical limits retained in the product

The interface describes the first download as approximately 500 MB and GPU memory as approximately 2 GB. Generation depends on WebGPU, available memory, and device performance. Source-based Research mode remains available without a model download. Model statements require checking against the cited evidence. Citation validity does not establish that every generated interpretation is correct. The workspace contains a saved public-data example and no authenticated client performance connection.

Deployment acceptance still includes the root reviewer's final production build and live HTTPS smoke checks after publishing.
