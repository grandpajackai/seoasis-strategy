# SEOasis — interview operating dashboard

Research date: 14 October 2026 (UTC). Public evidence only. This is an independent candidate preparation artifact, not a commissioned SEOasis audit.

## Delivery plan
1. Read the live job description and map the operator responsibilities.
2. Independently research SEOasis, inspect a bounded page sample, and record sources.
3. Complete specialized workstreams A–O below. Keep evidence distinct from proposals and unavailable account metrics.
4. Strategy Lead P reconciles all findings, rejects unsupported claims, prioritizes a backlog, and builds a realistic 90-day plan.
5. Frontend Q builds a responsive Next.js static application with a concise Interview Mode and deeper working views.
6. Independent QA R reviews evidence, flows, accessibility, production build, and job coverage. Fix observed defects and repeat targeted checks.
7. Publish the approved build to a public GitHub repository and GitHub Pages; verify the hosted routes and assets.

Four concurrent slots constrain staffing. Research agents run in independent specialist batches; the lead implements the shell in parallel. A separate synthesis pass follows research, then independent factual and product reviewers run a gauntlet against the completed artifact.

## Evidence contract
Each finding records classification (OBSERVED, INFERRED, OPPORTUNITY, REQUIRES INTERNAL DATA), confidence, evidence, and source IDs. Sources preserve URL, page title, UTC access date, and supporting note. Public marketing claims are attributed, not verified client outcomes. Readiness scores measure a disclosed public evidence rubric, not business performance or AI visibility. Unavailable metrics display “Requires Internal Access” with platform, metric, purpose, and decision.

## Review gates
- Job requirements are explicitly mapped to dashboard views.
- No private data, invented volumes, rankings, traffic, conversions, or AI output.
- Cohesive green/cream design complementary to the public brand.
- All views, filters, sorting, settings, downloads, and presentation steps work.
- TypeScript and production export pass; browser review covers desktop and mobile.
- Hosted build passes route, asset, and navigation checks.
